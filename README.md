# ADHYEY BROTHERS — Full-Stack E-commerce Platform

A production-ready e-commerce platform built with Next.js, Supabase, TypeScript, and Vercel.

> **Repository note:** This project was originally developed under the internal name `sastabazaronline` and is currently deployed for **ADHYEY BROTHERS**.

## Live Website

**https://www.adhyeybrothers.in/**

## Project Overview

ADHYEY BROTHERS is a full-stack e-commerce platform designed for real-world online retail operations.

The application combines a responsive customer storefront with product management, inventory, orders, checkout, shipping serviceability, coupons, analytics, SEO, and administrative business tools.

The project focuses on performance, mobile usability, maintainability, security, and production deployment.

## Key Features

- Responsive e-commerce storefront
- Product catalog and category management

## Admin System

The administration system provides centralized tools for managing products, categories, inventory, orders, customers, coupons, shipping, payments, reports, and other day-to-day e-commerce operations.

## Shipping & Checkout

The platform includes shipping-related business logic such as pincode serviceability checking, shipping-rate calculation, order-weight handling, COD and prepaid workflows, courier integration, and checkout validation.

## SEO & Search Visibility

SEO implementation includes SEO-friendly page structure, product metadata, structured data, sitemap support, search indexing preparation, performance optimization, mobile responsiveness, and search-friendly product content.

## Testing

The repository includes automated tests for important commerce logic, including:

- Pricing engine
- Order total calculations
- NimbusPost webhook handling

## Security Approach

Sensitive credentials are handled through environment variables and are not intended to be stored directly in the repository. Sensitive administrative and business operations use server-side application logic and authentication controls.
